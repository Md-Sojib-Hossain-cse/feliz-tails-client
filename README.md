# Feliz Tails 🐾 – Client (Frontend)

The **frontend** of Feliz Tails, a MERN stack-based pet adoption and donation platform. This React app allows users to browse and adopt pets, view and create donation campaigns, and securely process payments.

---

## 🚀 Features

- 🐶 View available pets and send adoption requests
- 💖 Create, browse, and donate to campaigns
- 📃 View your donations and campaign details
- 🔐 Role-based dashboards for users and admins
- 🧾 PDF receipts using `html2canvas` & `jsPDF`
- 🌟 Responsive, user-friendly UI built with TailwindCSS & DaisyUI
- 🔥 Firebase integration for media uploads
- 💳 Stripe integration for secure payments

---

## ⚙️ Tech Stack

- **React** – Frontend framework
- **React Router DOM** – Client-side routing
- **React Hook Form** – Form management
- **Zod** – Schema validation
- **Tailwind CSS + DaisyUI** – Styling
- **Firebase** – Image hosting
- **Stripe** – Payment gateway
- **TanStack Query** – Server state management
- **Radix UI**, **React Icons**, **Lucide**, **Moment.js** – UI enhancements
- **HTML2Canvas**, **jsPDF** – Generate receipts as PDFs
- **Axios** – HTTP requests
- **Vite** – Build tool
